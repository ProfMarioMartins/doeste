Como pesquisar no Corpus TEK

O Corpus TEK permite realizar buscas linguísticas por meio da linguagem CQP (Corpus Query Language), que possibilita localizar palavras, padrões gramaticais e estruturas recorrentes nos textos.

As buscas são feitas na caixa de pesquisa, onde é possível digitar diretamente uma expressão CQP. Também é possível utilizar a Construção de pesquisa para formular buscas sem escrever manualmente toda a expressão.

Exemplos de busca

Buscar uma palavra específica

[lemma="casa"]

Retorna as ocorrências cujo lema é casa, incluindo formas flexionadas presentes no corpus, como casa e casas.

Buscar padrões gramaticais

[lemma="casa"] [upos="ADJ"]

Retorna ocorrências de palavras com lema casa seguidas de um adjetivo.

Buscar uma classe gramatical

[upos="VERB"]

Retorna os verbos anotados no corpus.

Usando a Construção de pesquisa

Se o usuário não estiver familiarizado com a linguagem CQP, poderá utilizar o construtor de consultas:

  1. abrir a Construção de pesquisa;
  2. definir os critérios desejados, como Forma, Lema e Classe gramatical;
  3. combinar, quando necessário, esses critérios com os filtros documentais;
  4. executar a pesquisa.

Buscar documentos

A Busca por documento permite restringir os resultados por ID do Texto, Ano do ENEM, Tema oficial, Autor(a), Língua, Domínio e Propósito. Esses filtros podem ser usados isoladamente ou em combinação com os critérios linguísticos.

Sobre a linguagem de busca

  • word → forma efetivamente presente no texto;
  • lemma → lema ou forma lexical de referência;
  • upos → classe gramatical.

Em contrações analisadas como multiword tokens, os atributos dos componentes são agregados com +. Por exemplo, a forma da pode apresentar lema de+o e UPOS ADP+DET. Para examinar todos os componentes e suas relações individualmente, consulte a representação TEI/XML.
