Como pesquisar no Corpus TED

O Corpus TED permite realizar buscas linguísticas por meio da linguagem CQP (Corpus Query Language), que possibilita localizar palavras, padrões gramaticais e estruturas recorrentes nos textos.

As buscas são feitas na caixa acima, onde você pode digitar a expressão de busca. Também é possível utilizar o construtor de consultas.

Exemplos de busca

Buscar uma palavra específica

[lemma="casa"]

Retorna todas as ocorrências da palavra casa, independentemente de flexão (casa, casas).

Buscar padrões gramaticais

[lemma="casa"] [upos="ADJ"]

Retorna ocorrências de casa seguidas de um adjetivo.

Buscar classe gramatical

[upos="VERB"]

Retorna todos os verbos do corpus.

Usando o construtor de consultas

Se você não está familiarizado com a linguagem CQP, pode utilizar o :

  1. Clique no ícone do construtor de consulta 

  2. Defina os critérios (palavra, lema, classe gramatical etc.)

  3. Clique em Criar consulta

  4. Execute a busca

Buscar documentos

Para listar documentos do corpus, basta executar a busca sem definir palavras específicas. Isso permite explorar os textos disponíveis antes de realizar análises mais detalhadas.

Sobre a linguagem de busca

A linguagem CQP permite definir propriedades linguísticas como:

  • lemma → forma base da palavra

  • upos → classe gramatical

  • word → forma exata

Para mais detalhes, consulte a documentação do CQP.
